# 网络规划设计师案例分析答题模板 — 2026年下半年

> 适用于网络规划设计师案例训练；具体题量和选答规则以试卷为准。
> 最后核验：2026年8月4日

## 一、通用四步法

1. **定位要求**：圈出“指出、分析、计算、设计、说明理由”等动词。
2. **匹配理论**：写出标准术语、过程或公式。
3. **结合材料**：引用案例中的角色、系统、指标或错误动作。
4. **形成采分点**：一条只表达一个结论，按分值决定条数。

## 二、网络规划与故障分析题型映射

| 关键词 | 理论工具 | 答题重点 |
|---|---|---|
| 地址不足/网段划分 | VLSM/CIDR | 按主机量排序、计算前缀、保留增长空间 |
| 路由不可达/震荡 | OSPF/BGP/静态路由 | 邻居、路由表、策略、度量与汇总 |
| 二层环路 | VLAN/STP/链路聚合 | 根桥、端口角色、冗余和收敛 |
| 无线覆盖差 | 信道/功率/容量/漫游 | 现场勘测、同频干扰、AP密度、认证 |
| 性能下降 | 分层排障/QoS | 带宽、时延、抖动、丢包和队列 |
| 安全与机房 | ACL/VPN/防雷/接地/UPS | 分区分域、纵深防御、等级与验收指标 |

## 三、改错题模板

> 存在问题：材料中的【具体行为】不符合【规范/过程】。正确做法应为【动作1】，形成【文档/记录】，经【责任角色】审批或确认，并在【后续过程】中跟踪验证。

## 四、方案选择题模板

1. 选择：明确写出方案名称。
2. 匹配：逐条对应性能、可用性、安全、成本、周期等约束。
3. 风险：至少指出两个代价或限制。
4. 补救：给出监控、冗余、演练、回退或治理措施。

## 五、计算题模板

- 写已知量和单位。
- 写公式后再代入，不只写结果。
- 中间值保留合理精度。
- 最后用一句业务结论解释结果。

## 六、常见失分

- 只抄材料，不指出理论错误。
- 只写技术名称，不解释为什么适用。
- 一段话塞入多个采分点，阅卷难以识别。
- 计算缺少公式、单位或四舍五入依据。
- 忽略题目要求的“结合案例”。
