# 系统规划与管理师案例分析答题模板 — 2026年下半年

> 适用于系统规划与管理师案例训练；具体题量和选答规则以试卷为准。
> 最后核验：2026年8月4日

## 一、通用四步法

1. **定位要求**：圈出“指出、分析、计算、设计、说明理由”等动词。
2. **匹配理论**：写出标准术语、过程或公式。
3. **结合材料**：引用案例中的角色、系统、指标或错误动作。
4. **形成采分点**：一条只表达一个结论，按分值决定条数。

## 二、IT服务管理题型映射

| 关键词 | 理论工具 | 答题重点 |
|---|---|---|
| 服务频繁中断 | 事件/问题管理 | 先恢复服务，再做根因和已知错误管理 |
| 未授权变更 | 变更管理 | 申请、评估、审批、实施、验证、回顾 |
| SLA不达标 | 服务级别管理 | 指标定义、采集、报告、改进和责任边界 |
| 资源不足 | 容量管理 | 基线、趋势、预测、扩容、负载均衡和弹性 |
| 客户投诉 | 服务质量/满意度 | 数据证据、根因、纠正措施和效果复核 |
| 持续改进 | PDCA/指标体系 | 目标、指标、采集、分析、实施、标准化 |

## 三、改错题模板

> 存在问题：材料中的【具体行为】不符合【规范/过程】。正确做法应为【动作1】，形成【文档/记录】，经【责任角色】审批或确认，并在【后续过程】中跟踪验证。

## 四、方案选择题模板

1. 选择：明确写出方案名称。
2. 匹配：逐条对应性能、可用性、安全、成本、周期等约束。
3. 风险：至少指出两个代价或限制。
4. 补救：给出监控、冗余、演练、回退或治理措施。

## 五、计算题模板

- 写已知量和单位。
- 写公式后再代入，不只写结果。
- 中间值保留合理精度。
- 最后用一句业务结论解释结果。

## 六、常见失分

- 只抄材料，不指出理论错误。
- 只写技术名称，不解释为什么适用。
- 一段话塞入多个采分点，阅卷难以识别。
- 计算缺少公式、单位或四舍五入依据。
- 忽略题目要求的“结合案例”。
