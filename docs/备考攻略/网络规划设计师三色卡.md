# 网络规划设计师三色卡 — 2026年下半年版

> **统计口径**：依据本仓库现有近年真题中题干较完整、来源有标记的内容归纳。
> **颜色含义**：🔴 三科核心/反复出现；🟡 重点专题；🟢 新技术或低频观察。
> **重要说明**：颜色是复习优先级，不代表命题概率；“新技术观察”不计入历史频次。
> **最后核验**：2026年8月4日

## 使用方法

1. 红色知识点必须做到：能解释、能辨析、能在案例中分点作答。
2. 黄色知识点至少完成一组真题和一道案例/论文提纲。
3. 绿色知识点只掌握定义、架构组成、优缺点和典型场景，不追逐新闻名词。
4. 每做完一套真题，在卡片旁记录考次和题号；无题号证据时不要擅自修改“考频”。
