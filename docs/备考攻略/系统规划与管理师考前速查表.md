# 系统规划与管理师考前速查表 — 2026年下半年

> 用途：考前30分钟与每次模考前快速激活记忆。
> 最后核验：2026年8月4日

## 核心速记

1. SLA面向客户，OLA约束内部，UC约束外部供应商
2. 事件管理尽快恢复服务；问题管理寻找根因和防复发
3. 变更必须评估、审批、实施、验证和回顾
4. 配置项关系和状态由配置管理体系维护
5. 容量管理同时关注业务、服务和组件容量
6. 可用性关注服务可用比例、故障间隔和恢复时间
7. 持续改进形成目标→指标→采集→分析→实施→评价闭环
8. SMART：具体、可衡量、可实现、相关、有时限
9. 云服务选择不能只看成本，还要看控制权、安全、弹性与运维
10. 论文角色应体现IT服务规划/管理职责和过程指标

## 案例答题检查

- 先读问题和分值，再读背景。
- 一分通常对应一个明确采分点；使用编号短句。
- 计算题写公式、代入、单位和结论。
- 方案题同时写选择、理由、风险与补救措施。
- 题目要求“结合案例”时必须引用材料中的对象、指标或问题。

## 论文提交前检查

- 项目和本人角色符合系统规划与管理师职责。
- 三个子问均有对应小节，不遗漏。
- 理论正确但不过量，主要篇幅用于项目实践。
- 至少写两个实际问题、解决办法和量化效果。
- 项目规模、周期、人数、成本和效果数据前后一致。

## 机考切换

- 上午综合知识150分钟，至少作答120分钟。
- 下午案例与论文连考210分钟；案例提交后不能返回。
- 建议案例75—90分钟，给论文保留120—135分钟及检查时间。
