# 系统分析师考前速查表 — 2026年下半年

> 用途：考前30分钟与每次模考前快速激活记忆。
> 最后核验：2026年8月4日

## 核心速记

1. 需求必须可追踪：业务目标→用户需求→系统需求→设计/测试
2. DFD平衡：父图输入输出必须与子图一致
3. 用例关系：include复用必做行为，extend在扩展点附加行为
4. 2NF消部分依赖，3NF消非主属性对码的传递依赖
5. RPO衡量可丢数据时间，RTO衡量恢复服务时间
6. 同步复制一致性强但增加延迟；异步复制性能好但存在数据窗口
7. 边界类交互、控制类编排、实体类承载领域状态
8. 测试覆盖强度不能简单认为条件覆盖一定包含判定覆盖
9. 论文角色写系统分析师，重点体现分析、建模与决策依据

## 案例答题检查

- 先读问题和分值，再读背景。
- 一分通常对应一个明确采分点；使用编号短句。
- 计算题写公式、代入、单位和结论。
- 方案题同时写选择、理由、风险与补救措施。
- 题目要求“结合案例”时必须引用材料中的对象、指标或问题。

## 论文提交前检查

- 项目和本人角色符合系统分析师职责。
- 三个子问均有对应小节，不遗漏。
- 理论正确但不过量，主要篇幅用于项目实践。
- 至少写两个实际问题、解决办法和量化效果。
- 项目规模、周期、人数、成本和效果数据前后一致。

## 机考切换

- 上午综合知识150分钟，至少作答120分钟。
- 下午案例与论文连考210分钟；案例提交后不能返回。
- 建议案例75—90分钟，给论文保留120—135分钟及检查时间。
