# 网络规划设计师学习路线（2026年下半年）

> **考试日期**：2026年10月24日至27日，具体批次以准考证为准
> **考试形式**：机考；综合知识150分钟，下午案例分析与论文连考210分钟
> **最后核验**：2026年8月4日

## 一、能力主线

网络需求与规划、路由交换、IPv4/IPv6、WLAN、网络安全、机房与综合布线、性能和运维。

三科必须同时过线。建议把目标定为：综合知识稳定55分以上，案例能在90分钟内完成，论文能在剩余120—150分钟内完成审题、提纲、正文和检查。

## 三、8周速成计划

1. **第1—2周**：教材框架 + 核心概念，每周150道分领域题。
2. **第3—4周**：专业核心专题 + 每周3道案例。
3. **第5—6周**：近年真题；每周一篇论文提纲，每两周一篇全文。
4. **第7周**：两次案例限时训练，综合知识稳定在52分以上。
5. **第8周**：全流程模考、错题与速查表，不再扩展低频内容。

## 四、4周冲刺计划

| 周 | 综合知识 | 案例 | 论文 |
|---|----------|------|------|
| 1 | 一套诊断卷 + 高频专题 | 2题不限时复盘 | 建立2个项目素材 |
| 2 | 两套真题，逐项纠错 | 1套限时 | 2份完整提纲 |
| 3 | 一套模拟 + 错题重做 | 1套限时 | 1篇限时全文 |
| 4 | 速查表和易错点 | 只看模板与错题 | 项目数据、结构和打字检查 |

## 五、案例与论文重点

- **案例重点**：地址规划、路由交换配置、IPv6、WLAN、安全、机房与综合布线、性能诊断。
- **论文重点**：企业网络规划、IPv6、无线覆盖、网络安全、数据中心、SDN/云网融合。
- 案例按“结论—依据—结合材料”分点作答；计算题写公式和过程。
- 论文准备真实项目事实卡：背景、规模、角色、技术/流程、三个问题、三个解决方案、量化效果。

## 六、每周量化验收

- 选择题：标准档每周150题，正确率从60%提升到75%以上。
- 案例：第5周起每周至少2题，第9周起每周1套。
- 论文：至少5份不同主题提纲、2篇限时全文。
- 错题二刷正确率低于85%时，不进入下一知识域。

## 七、考试日策略

1. 上午先做确定题，计算和陌生题标记后回看。
2. 下午先浏览全部案例再确定选题；提交案例后不能返回。
3. 论文先用5—8分钟列提纲，逐项对应题目子问。
4. 最后检查题号、单位、术语、段落和字数。
